# 学生请假管理系统-python
### 1、系统功能
学生请假管理系统，后端基于 Python 3.12 + FastAPI，前端基于 Vue3 + Element Plus + JavaScript，数据库使用 MySQL 8.0，实现从学生管理、教师管理、班级管理、请假类型管理、请假申请、请假审批到请假统计的全流程闭环！

· 登录

· 首页（仪表盘统计数据）

· 我的请假：请假申请、我的请假

· 请假管理：请假审批、审批记录、请假统计

· 基础设置：学生管理、教师管理、班级管理、请假类型管理

· 系统管理：菜单管理、角色管理、账号管理
